# 2026.276.1533 — feat(vm): stable :latest handle for the emitted box (successor to #61)

## Summary

Emit a **stable `:latest` handle** alongside the wall-clock CalVer tag when a VM box is built, so a consumer that must **name the box statically** — a `kind:kubevirt` `containerDisk.image` (charly.yml's `localhost/charly-check-kubevirt-vm-box:latest`), or any authored ref — resolves the same image the CalVer tag does. The CalVer tag is unknowable ahead of the build; `:latest` is not.

The handle is produced on **both** the local image and the pushed destination, through **ONE** `latestRef` derivation shared with the `--push` path (R3: the two cannot diverge).

This is the successor of the auto-closed **`opencharly/plugin-vm#61`** — carried forward on the operator's **break A** direction (same cycle break as `plugin-kubevirt#4`→`#10`): rebased onto current `main`, sdk/spec pins taken from `main` (no regression), and opened so `charly#730` can cite a landing producer for its last `feat/*` pin.
