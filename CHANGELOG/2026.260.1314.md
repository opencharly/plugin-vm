# 2026.260.1314 — chore: gitignore .claude/worktrees/

## Summary

Adds `.gitignore` with `.claude/worktrees/`.

**The defect (RCA).** `AGENTS.md` "Hard Cutover by Default" mandates every session
work in `.claude/worktrees/<slug>/`. That path is per-session, per-machine
ephemeral state and must stay out of git (the charly repo ignores `.check/` and
`scratchpad/` for the same reason). This repo had no `.gitignore` at all, so a
checkout following the mandated convention reads dirty.

**Consequence:** the umbrella's `scripts/verify-pins.sh` fails with
`FAIL: <this repo>: dirty working tree` on a tree that is actually clean of source
changes.

## How tested

```
$ git check-ignore -v .claude/worktrees/
.gitignore:7:.claude/worktrees/	.claude/worktrees/
$ git status --short
(clean — only the new .gitignore is staged)
```

## Rulebook compliance

- R1: the failure was root-caused (missing ignore entry for the mandated dir).
- R3: one entry, matching the charly convention.
- R4: fixed at the source, not worked around per-checkout.
