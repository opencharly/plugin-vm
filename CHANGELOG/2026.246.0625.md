# 2026.246.0625 — feat(vm): emit a VM box image after every vm build (cutover task 3)

## Summary

Cutover-plan task 3 (VM box emission) for plugin-vm: `charly vm build` now
finishes every successful source-kind build with a **box-emit step** that wraps
the materialized disk + the resolved entity's metadata into a VM box image in
local engine storage — an OCI image whose labels carry the
`spec.VmBoxMetadata` contract (whole-struct JSON on `ai.opencharly.vm.box`)
and whose single layer carries the disk artifact at `/disk.qcow2` (emitter:
`deploykit.EmitVmBox`, sdk #202; read-back: `deploykit.VmCapabilitiesFromLabels`,
the future `charly fleet from-box vm:<ref>` surface of cutover task 5).

- **Pin bump**: sdk `v0.2026242.1217` → `v0.2026246.613` (tag-on-merge tag of
  sdk PR #202, commit 5e5c55f); spec resolves to `v0.2026246.554` (spec PR #90,
  VmBoxMetadata/VmBoxSource/LabelVmBox) via MVS in `go mod tidy`.
- **`vm_box_emit.go`** (new): `buildVmBoxMetadata(vmName, vmSpec)` maps the
  resolved VmSpec onto `spec.VmBoxMetadata` (distro/base_user from the source,
  firmware/ssh_user/charly_install from the entity, arch = host GOARCH, version =
  current CalVer via `spec.ComputeCalVer`, source provenance kind+from_vm/
  from_snapshot/box/url, description "charly VM box for <name>"); `emitVmBox`
  tags the box `localhost/charly-<vmName>:<CalVer>` (the local-storage CalVer
  convention bootc images already use) and returns the ref. bootc/clone sources
  carry no `source.distro`, and reading a distro out of a box image is the BoxRef
  resolver's job (cutover task 4) — those boxes emit an empty distro rather than a
  guessed one (best-effort, documented in the code).
- **`vm_build.go`**: `runVmBuildDrive` now records the built disk per source
  kind (cloud_image/bootc/bootstrap/iso/clone) and emits the box once in a shared
  tail — prints `Wrote VM box <ref>`. **Best-effort by contract**: a missing
  engine or a failed emit prints a warning and the disk build stays the primary
  artifact; the build never fails on box emission.
- **`vm_box_emit_test.go`** (new): metadata-mapping test, label JSON round-trip
  test, and a podman-gated live emit/read-back integration test
  (`TestEmitVmBoxReadBackRoundTrip`, passed live on this host).
- **`vm_clone_test.go`**: gofmt whitespace fix only (trailing blank line) —
  pre-existing on main (see How tested), included so `gofmt -l .` is empty.
