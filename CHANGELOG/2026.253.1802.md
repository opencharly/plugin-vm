# 2026.253.1802 — fix(vm-build): the clone drive uses the LEAF entity name for a namespace-qualified ref

## Summary

The clone drive (from: ns.entity:snapshot) resolved the qualified ref to the template, but the snapshot registry + disk paths + domain lookup are keyed on the ENTITY name as authored in the owning repo — the qualified name (omarchy.check-charly-omarchy-vm) failed LookupSnapshot with "snapshot golden does not exist". The drive now strips the namespace prefix (entityLeaf) for the entity-name-keyed operations: FromVm, BuildClone, vmDiskDir. The qualified ref stays the cross-repo reference; the leaf is the registry key.

- **vm_build_resolve.go**: entityLeaf() + applyCloneDriveSource uses the leaf
- **vm_build.go**: the clone case builds under the leaf entity name
- **tests**: entityLeaf (4 cases) + the qualified drive wiring
